2026-10-27 사전 조사에 따라 작성한 구현 기준이다. 실행 API나 지원 완료를 의미하지 않는다.

라이브러리는 효과를 계산·적용하지 않는다. API 보고값과 해석값을 구분하고 모르는 필드는 원본 트리에 보존한다. 각 문서의 규칙을 양쪽 언어에 적용하며 기대 결과 검증으로 차이를 탐지한다.

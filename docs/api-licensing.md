# 코드 라이선스와 API 이용 조건

확인일: 2026-10-28. 자체 작성 코드에 MIT를 적용하는 것을 명시적으로 금지하는 조항은 확인하지 못했다. 이는 공개 문구에 근거한 검토이며 넥슨의 개별 승인이나 법률적 확정 판단은 아니다. 사용자 요청에 따라 MIT를 적용했다. 저작권자는 기존 Git 작성자 설정인 Kimgooner로 표기했다.

코드에 적용할 라이선스는 넥슨 API, 결과 데이터, 게임 이미지·문구 및 제3자 저작물의 권리를 재허락하지 않는다. 실제 API 이용자는 별도 약관·정책을 준수하고 자신의 키를 사용해야 한다. 소스 공개와 API를 중계하는 서비스 운영은 구분한다. 데이터 재배포·영리 이용은 별도 조건을 확인한다.

- [공식 약관](https://openapi.nexon.com/ko/support/terms/): 제5조①~⑤, 제6조①~⑥.
- [출처 표기 안내](https://openapi.nexon.com/ko/guide/request-api/): Data based on NEXON Open API.
- [MIT 원문과 적용 방법](https://choosealicense.com/licenses/mit/).

MIT 원문을 수정하지 않고 루트 LICENSE와 배포 패키지에 포함한다. API 관련 경계와 출처는 README의 별도 안내로 유지한다. 라이브 키·캐릭터 원본·게임 이미지는 배포물에 포함하지 않는다.

# Offline v1 기대 결과 검토

cases/offline-v1.json의 expected는 구현 결과에서 생성하지 않고 아래 의미를 기준으로 작성했다.

- 심볼 DEX 20→25 차이5. 큰 HP 소수 .01→.03 차이 .02.
- 숫자 표기4.50→4.5 차이0, 원문 변화만 존재.
- missing/null/invalid/0 독립 상태. unknown의 숫자처럼 보이는 문자열에는 delta 없음.
- 장비는 유일 슬롯으로 대응하여 배열 순서만 바뀐 모자는 변화 없음. 무기 공격력30→31만 변화.
- 없는 프리셋에 빈 배열이 생기면 명시적 추가. 미선택 문서는 삭제하지 않음.
- 규칙 버전 차이일 때 의미 delta 생략. 잘못된 배열은 비교 범위에서 제외.
- 중복 슬롯은 진단과 index 비교. 프리셋2가10보다 먼저, Unicode code-point 정렬.

모든 입력은 합성이며 키·실제 캐릭터 자료는 없다. 이 파일 형식과 테스트 projection은 공개 저장 계약이 아니다.
